AI Content Flag

Bewertet längere Textabsätze mit einem KI-Text-Klassifikator und markiert sie grün / gelb / rot. Scores sind Schätzungen – sie können sich irren, besonders bei kurzen, übersetzten oder stark redigierten Texten.

Allgemein

Extension aktiv
Tastenkürzel: Alt+Shift+A (an/aus), Alt+Shift+S (Seite scannen)
Wann wird gescannt?
Eine Domain pro Zeile, Subdomains sind eingeschlossen.

Erkennungs-Backend

Erwarteter Vertrag (shim_server.py erfüllt ihn unter /v1/score):
POST {"texts": ["…", "…"], "model": "…"}
→    {"scores": [0.93, 0.12]}   // KI-Wahrscheinlichkeit 0..1 pro Text
Muss als Textklassifikation über „HF Inference“ verfügbar sein (Modellseite → Deploy → Inference Providers).
Wird nur lokal in diesem Browser gespeichert, nicht synchronisiert.

Textausschnitte (bis 500 Zeichen pro Absatz) werden an gesendet. Nutze „Nur auf Knopfdruck“ oder eine Seitenliste, wenn du das nicht für jede Seite willst.
