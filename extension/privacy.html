Privacy Policy

AI Content Flag (browser extension) · As of: 2026-09-25

The extension scores paragraphs of text on web pages with an AI-text classifier. It collects no usage statistics, contains no advertising or trackers and does not sell or transfer any data to third parties – except to the detection backend that you choose yourself (see below).

What data is processed

  • Page text: Visible paragraphs of text are read from scanned pages (up to 2000 characters per paragraph, about as much as the detection model can process at once). No HTML, no form input, no passwords.
  • Settings: chosen options, site list and blocklist. They are stored in chrome.storage.sync and – if enabled in the browser – are synced via your browser account.
  • Credentials for custom servers or Hugging Face (API key, token) are stored only locally in this browser (chrome.storage.local) and are not synced.
  • Stored scores: per paragraph a fingerprint (128-bit hash), score, model and time – no text and no address. Local only (IndexedDB), 30 days by default, adjustable down to "Do not store", deletable at any time.
  • Feedback (voluntary): If you state in the check result where a text comes from and agree to storing, the extension stores the checked text (up to 2000 characters), your answer, score, model, the language of the page and the time – no address. Local only (IndexedDB), with no deletion deadline, is never transmitted. On blocklisted sites and on sites with a password or payment field no feedback is offered. Export, deletion and withdrawal of consent: Settings → Feedback.

Where texts are sent

  • In the browser (default) and Local (server on this computer): texts do not leave the computer. The only outside connection is the one-time model download from Hugging Face; no page content is transmitted in the process.
  • Custom server / cloud: The paragraphs go to the address you entered. The operator of that server is responsible for the processing there.
  • Hugging Face Inference API: The paragraphs go to Hugging Face (router.huggingface.co). The privacy policy of Hugging Face applies.

The settings show a notice as soon as a backend sends texts off the computer.

When scanning happens

  • By default only on sites that you explicitly allow. Without permission the extension reads no text and does not observe the page.
  • Blocklist: Webmail, online banking, payment services and government portals with a login are never checked automatically or via "Scan page now". The bundled list (around 14,000 domains) is built into the extension and is not reloaded from the network – so nothing is reported anywhere about which sites you visit. Own entries and exceptions are possible in the settings and in the popup.
  • Password and payment fields: If a page shows a password, credit card or one-time-code field, it is likewise not scanned (can be switched off). For this the extension only reads whether such a field exists – never its content.
  • On blocked sites individual passages can only be checked by deliberate selection or right-click – the extension then points this out and, for external backends, names the destination.
  • In the browser's PDF viewer nothing is scanned automatically. Only text you select there and check via right-click is scored; the result appears in the usual popover (or, if the page cannot show one, in a small window of the extension).
  • PDF viewer: PDFs are only opened in the extension's own viewer when you ask for it (popup, file picker, drag and drop). A PDF behind a web address is loaded a second time by the extension – only after you allowed access to that site. PDF scripts are never executed. A PDF is only checked when you click "Scan PDF"; its text is then handled like page text, but only by the backends that stay on this computer ("In the browser", "Local"). Online backends for PDFs are off by default; if you switch them on in the settings, the viewer still asks before every document and names the destination and the amount of text.
  • The main switch (Alt+Shift+A) stops all processing.

Permissions

  • Access to web pages (content script): to read paragraphs and mark them in color.
  • Tabs: address of the active tab for popup, permission and blocklist.
  • Storage, alarms: settings and stored scores, daily cleanup.
  • Context menu, offscreen document: right-click check and model in the browser, respectively.
  • Host access to external backends is only requested when you save such a backend.

Deleting

"Delete all" under "Stored scores" removes all scores, "Delete" next to the model removes the download, "Delete and withdraw consent" under "Feedback" removes the feedback collection. When the extension is uninstalled, the browser removes all locally stored data.

Contact

The developers receive no data whatsoever from the extension – there is no project server to which anything is sent. Please direct questions and comments via the project's GitHub issues.
