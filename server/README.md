# Lokaler Inferenz-Server

**`shim_server.py`** (Port `8787`) ist der einzige Endpunkt, den die Extension anspricht.
Routet je nach `model`-Feld zu einem von drei Backends:

- **`tmr`** ("Low" in der Extension) — `Oxidane/tmr-ai-text-detector`, RoBERTa-base 125M,
  lokal geladen. Standard-Backend.
- **`desklib`** ("Medium") — `desklib/ai-text-detector-v1.01`, DeBERTa-v3-large 430M,
  lokal geladen. Deutlich genauer, aber spürbar langsam/schwer — siehe Performance-Werte
  unten. Eigene Pooling-Architektur (kein `AutoModelForSequenceClassification`), im Shim
  nachgebaut inkl. Kompatibilitäts-Fix für `transformers>=5`.
- **`english` / `multilingual`** (Laya, Proxy zu `laya-serve`, Port `11500`) — **aktuell
  nicht in der Extension-UI wählbar**, weil Zero-Shot unbrauchbar ist (siehe unten).
  Code/Routing bleibt vorbereitet, für den Tag, an dem ein fine-getunter Laya-Checkpoint
  existiert (`../training/README.md`).

## Start (nur das, TMR/desklib brauchen kein `laya-serve`)

```powershell
cd server
uv venv .venv --python 3.12
uv pip install --python .venv -r requirements_shim.txt
.venv/Scripts/python.exe shim_server.py
```

Läuft auf `127.0.0.1:8787`. TMR/desklib laden lazy beim ersten Request mit diesem
`model`-Wert (TMR ein paar Sekunden, desklib länger + ~1,8GB Download beim allerersten Mal).

```powershell
Invoke-RestMethod http://127.0.0.1:8787/healthz
# {"ok": true, "laya_upstream": true/false, "tmr_loaded": ..., "desklib_loaded": ...}
```

## `/v1/score` — der Endpunkt, den die Extension nutzt

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8787/v1/score -Method Post -ContentType "application/json" `
  -Body '{"model": "tmr", "texts": ["Maintaining a bicycle in good working condition requires regular attention."]}'
# {"model": "tmr", "scores": [0.98...]}
```

Für Betrieb als „Eigener Server / Cloud“ (Extension-Provider `custom`):
`AIVSAI_HOST=0.0.0.0`, `AIVSAI_PORT`, `AIVSAI_API_KEY` (dann ist
`Authorization: Bearer <key>` Pflicht). Vor einem öffentlichen Deployment trotzdem
TLS/Reverse-Proxy davor setzen.

## Laya-Wire-Format `/v1/systemone` (Legacy, verifiziert)

```powershell
$body = @{
  model     = "tmr"   # oder "desklib"
  state     = @{ candidates = @(@{ text = "Maintaining a bicycle in good working condition requires regular attention." }) }
  questions = @{ c0 = @{ type = "noul"; instructions = "Is candidates[0].text primarily generated by an AI/LLM?" } }
} | ConvertTo-Json -Depth 6

Invoke-RestMethod -Uri http://127.0.0.1:8787/v1/systemone -Method Post -ContentType "application/json" -Body $body
```

## Verifizierte Befunde (2026-09-23) — Details/Reproduktion: `../training/EVAL_RESULTS.md`

Genauigkeit (100 balancierte HC3-Beispiele) UND Performance (CPU, 25er-Batch wie
`extension/content.js` verwendet) zusammen betrachtet:

| Backend | AUROC | Accuracy (beste Schwelle) | 25er-Batch | RAM |
|---|---|---|---|---|
| Laya zero-shot | 0.549 | 0.570 | ~61s | ~2,1GB |
| **TMR** | 0.911 | 0.830 (Schwelle 0.98) | ~1,6s | ~900MB |
| **desklib** | 0.998 | 0.990 (Schwelle 0.87) | ~2 Min | ~4,65GB |

- Laya zero-shot: praktisch Münzwurf, durch keine Schwelle behebbar — deshalb in der
  Extension deaktiviert, bis fine-getunt.
- desklib ist am genauesten, aber auf CPU ~80× langsamer als TMR und ~5× mehr RAM — für
  automatisches Scannen jeder Seite unpraktikabel, eher für gezielte Einzelprüfung gedacht.
- Batch-Format (`state.candidates[]` + `noul`-Frage pro Index) funktioniert identisch für
  alle drei Backends über den Shim.

### Zwei Bugs unterwegs gefunden

- `laya-serve`s echter Health-Endpoint heißt **`/health`**, nicht `/healthz` wie
  ursprünglich recherchiert (verifiziert per `GET /openapi.json`).
- desklibs 2024er Beispielcode aus der Model Card crasht ungepatcht mit `transformers>=5`
  (`AttributeError: ... 'all_tied_weights_keys'`) — gefixt durch eine überschriebene
  Property (leeres Dict), siehe `shim_server.py`.

## Optional: `laya-serve` starten (nur für Laya-Backends, aktuell ungenutzt)

```powershell
.\run_server.ps1
# oder manuell:
docker run -d --name laya -p 127.0.0.1:11500:11500 -e LAYA_MODELS=english ghcr.io/ouijan/laya-serve
```

## Stoppen

```powershell
docker stop laya; docker rm laya    # falls laya-serve lief
# shim_server.py: Strg+C im laufenden Terminal
```
