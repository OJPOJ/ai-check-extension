# WP-11 · Broaden the BYOM reference set (TODO item 1)

## Starting point
"Check model" (`extension/bg/model-check.js`) sends a reference set (`extension/bg/reference-set.js`,
generated by `training/build_reference_set.py`) to a custom model and derives AUROC,
traffic-light thresholds and AI label from it. So far: 20 human + 20 AI from HC3 (ChatGPT 2023), 400–1200 characters,
five HC3 domains. TODO item 1: thresholds rest on 20 human texts, short paragraphs are missing entirely.

## Goal
A broader, **redistributable** reference set: more domains, more recent generators, short
paragraphs as well – while keeping runtime/costs for cloud backends reasonable (order of magnitude 100–150 texts,
justify it).

## Scope
1. **Licences first.** The set is shipped with the extension. The source can be the eval suite
   (`C:/_programme/DS/aivsai/training/data/eval_suite.jsonl`, from `Jinyan1/COLING_2025_MGT_en`), but:
   the compilation has no licence, nor does M4GT-Bench. MAGE is Apache-2.0, HC3 CC BY-SA 4.0 –
   the **human source texts**, however, have their own licences (e.g. Wikipedia CC BY-SA, Yelp/IMDb
   datasets with their own terms of use, XSum/CNN from news articles, arXiv per paper).
   Clarify per sub-source whether redistribution is permitted, and take only such parts. Result as a
   table in the report and as a comment in `build_reference_set.py`. When in doubt, leave it out.
2. **Build the set** (extend `training/build_reference_set.py`): human/AI balanced, several domains,
   AI from several generators (as far as licensing permits), lengths mixed incl. short paragraphs
   (e.g. 40–119 words and ≥ 120 words separately, so that "Check model" could later derive `reliableWords`/
   `shortRedFrom`). Add `words`/`generator` to the fields in the JS if needed.
3. **Adapt the model check** (`extension/bg/model-check.js`): deal sensibly with the larger set
   (batching as before, progress/runtime, threshold suggestion). If short/long can be evaluated separately
   with the set: add a `reliableWords`/`shortRedFrom` suggestion – only if that is statistically
   defensible with the set, otherwise give reasons in the report why not.
   Run `training/build_reference_set.py --check tmr desklib`: AUROC/thresholds of the known
   models on the new set as a plausibility check (should roughly match the eval suite).
4. **Licence notices:** adapt `extension/about.html` if the licence of the reference set changes.
   Deliver text for `extension/THIRD_PARTY_NOTICES.md` and the README section "Licence" **only in the
   report** (the files belong to WP-09 and the orchestrator respectively).
